## 材料边

只写真实依赖：`上游产物 -> 下游所需材料`。不要用边表示“习惯上下一步”。

```text
<artifact-a> -> <node-b>
<artifact-c> + <artifact-d> -> <node-e>
```

## 选择规则

- 把用户对话、文件、链接和已有产物视为当前材料集合；先判断此刻是否真的需要技能。
- 只从真实可发现的技能中选择能直接缩小当前缺口的下一段最小子图，执行后重新判断，不预排完整路线。
- 无依赖且同时有用的节点才并行；已经存在且可验证的产物不重做。
- 反馈边必须写停止条件；外部副作用前设置授权闸门。
- 隐式调用时在 commentary 中标注技能、原因、实际输入和预期产物；默认不新建调用轨迹文件。
