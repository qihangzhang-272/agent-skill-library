# Agent 返回质量验证清单

主对话收到 agent 返回内容后，**逐条检查**，不通过则派 agent 重拉。

| 检查项 | 判断标准 | 不通过时操作 |
|--------|---------|------------|
| 无概括标记 | 内容不含"核心要点""主要观点""搜索总结""关键发现""此处省略""以下概括"等词 | 重拉，prompt 强调"禁止概括" |
| 微信/网页完整性 | 长文正文 > 5000 字节 | 重拉，增大 maxCharacters |
| 推文完整性 | 每条推文 > 100 字节 | 重拉，强调逐条完整 |
| Reddit 完整性 | selftext > 50 字节（短贴除外） | 重拉 |
| Twitter 逐条 | 每条推文 > 50 字且含完整 text（不含省略标记） | 重拉 |
| 文件落盘目录 | 所有 md 写入 `{platform}/` 子文件夹，不散落根目录 | `mv` 到正确位置 |
| 无临时文件泄漏 | 根目录无 `*.json`、`*_results.txt`、`*完整全文*.md` | `rm` 清理 |
