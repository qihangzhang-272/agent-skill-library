# Governance Docs

这里放仓库级原则，不放某个板块的候选来源或实验结果。

## 当前文件

- `architecture.md`：技能库整体架构、分层和边界。
- `project-purpose.md`：仓库为什么存在、给谁用、和外部资料源的边界。
- `reference-policy.md`：引用式技能库规则、资料正文不复制原则、外部包迁移例外。
- `library-constitution.md`：技能库长期约束、收录问题、复制边界和插件分发规则。
- `catalog-schema.md`：技能总账和 Claude Code plugin 分发映射的记录方式。

## 放置标准

只有影响整个技能库维护方式的规则才放这里。外部来源清单放到 `qihang-skill-index`；可复用调用链放到 `docs/workflows/`。
