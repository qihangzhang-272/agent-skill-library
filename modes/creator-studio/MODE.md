# Creator Studio

面向公众号、X、长内容研究、视觉表达和发布准备的长期创作工作场。

## 能处理的目标

公开信息与给定素材研究、选题判断、正文写作和编辑、视觉叙事、配图与漫画、Markdown/HTML 排版、图片压缩和发布准备。写作、视觉、排版或发布准备可以单独发生，不要求走完整链条。

## 常驻与按需上下文

常驻只包含精简 Profile、本 Mode 边界和 Skill catalog。具体账号语料、Case 草稿、历史反馈、参考文章、截图和完整 Skill 正文只在目标需要时读取。

## 动态组合

Host 根据当前 Goal 选择最小完整 Skill 集。研究、写作、视觉和排版之间没有预存顺序；上游材料已完整时可以直接进入编辑或排版，视觉任务也不必触发正文重写。

## 边界与授权

本 Mode 不自动进入产品投资判断、估值或尽调。外部发布、登录、私人数据读取和破坏性覆盖必须得到当轮明确授权。受第三方许可限制的 Skill 继续遵守自身 `SOURCE.md` 与许可边界。

## 典型产物与演化

典型产物包括研究材料包、Markdown 成稿、配图、信息图、漫画、微信兼容 HTML 和待发布草稿。只有反复出现的能力面或上下文边界问题才修改 Mode；单篇内容问题留在 Case 或责任 Skill。
