# Linear 工作流

Linear 用于跟踪技能库的收录、审查、去重和重构。

## 项目

推荐项目名：`高质量 Agent 技能库`

## Issue 类型

| 类型 | 说明 |
| --- | --- |
| 收录 | 新增一个技能索引或技能卡片 |
| 审查 | 判断技能是否高质量、是否重复、是否可迁移 |
| 去重 | 合并相似技能，避免多个技能解决同一问题 |
| 引用修复 | 框架路径变化后更新技能引用 |
| 迁移 | 把来源技能转为更通用的私有技能实现 |

## 每个技能至少记录

- 技能名
- 分类板块
- 来源路径
- 触发场景
- 依赖框架路径
- 是否复制正文
- 下一步动作
