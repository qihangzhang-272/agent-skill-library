# Linear 工作流

Linear 用于跟踪技能库的收录、审查、去重和重构。

## 项目

推荐项目名：`高质量 Agent 技能库`

## Issue 类型

| 类型 | 说明 |
| --- | --- |
| 收录 | 新增一个技能索引或技能卡片 |
| 审查 | 判断技能是否高质量、是否重复、是否可迁移 |
| 去重 | 合并相似技能，避免多个技能解决同一问题 |
| 引用修复 | 来源链接、配置方式或调用边界变化后更新索引 |
| 迁移 | 把明确可复用的外部技能包或子集迁入正式库 |

## 每个技能至少记录

- 技能名
- 分类板块
- 来源路径
- 触发场景
- 依赖来源、配置方式或上游 repo
- 是否复制正文
- 下一步动作

## 当前治理重点

1. 每个技能先进入板块和 catalog，再决定是否需要 vendored。
2. 每条能力链路都要能解释：什么时候调用、怎么组合、如何验证。
3. Linear 负责记录“哪些要、哪些不要、哪些待验证”。
4. 后续如果上游更新，按 commit 记录同步，不自行混合改写。
