# 公众号选题与内容效果研究

本参考服务于公众号选题和对标研究，不提供平台内部算法。2026-09-06 维护时删除了旧版无来源的推流阶段、曝光公式、标题点击率排序和赛道收益断言。下面是观察角度与可检验的编辑假设，不能直接写成微信官方规则。

## 先知道为哪个读者和账号目标研究

从用户现有定位和本次问题出发。个人 IP、知识服务和泛流量内容的目标不同，不能把其他赛道的单篇阅读量当统一标准。混合题材先看共同读者与持续问题，不直接诊断“标签混乱”。

查找选题时，关注读者反复提问、真实实践中的困难、尚未解释清楚的变化。热点只是来源之一；有无新证据、与目标读者的关系、是否能持续获得材料，比照搬热门标题更有用。小众但重要的问题可以成立，不强制已有爆款才允许写。

## 对标样本与证据

- 优先读取原帖、完整文章或完整相关段落，标注作者、日期、平台与抓取状态。长文入口推文只有链接时，应读取 Article，不能把入口当全文。
- 不只选表现最好的案例；可获得时补充同账号、同类题材的普通表现样本。没有完整样本总体就说明抽样偏差。
- 分清公开互动指标、作者展示的后台截图、收益自述、产品推广和平台官方声明。截图并不能独立证明收益归属、代表性或某个方法的因果效果。
- 作者同时推广某个工具时如实记录关联表述。没有公开证据不要推断持股、创始人身份或商业分成。
- 对标拆解的编辑方法归 `public-account-writing-style/references/account-editorial-practice.md`；本 Skill 保存原始材料和证据强弱，不另写一套爆款评分器。

## 与写作相关的观察问题

| 角度 | 研究时找什么 | 不能偷换成什么 |
|---|---|---|
| 选题需求 | 具体读者问题、讨论分歧、实践案例 | 热度就代表适合本号 |
| 阅读入口 | 标题和封面承诺、开头如何交代问题 | 数字标题一定更好、固定开头秒数 |
| 内容价值 | 新事实、真实比较、可用方法、明确边界 | 改几个词就是原创 |
| 视觉节奏 | 图片如何解释场景、关系、证据或转折 | 所有文章用同一张人物海报 |
| 反馈与持续性 | 统计窗口、来源结构、可归因反馈、制作成本 | 阅读低即限流、某收益图即普遍回报 |

## 算法与工具说法如何处理

公众号内部推荐权重、固定流量池阈值、AI 检测触发线、统一黄金发布时间等，只有取得适用且当前的官方说明时才能作为平台规则。创作者讲的比例、天数和公式保留在原始材料中，分析时标“作者经验 / 未验证”，不沉淀成全局阈值。

ContentAny 在本 Environment 中是用户指定的公众号发布前硬性参考，且最终整稿 AI 指数须为 0%–20%（含 20%），超过禁止发布；实际送检与编辑复核契约由 `baoyu-post-to-wechat/references/contentany-gate.md` 维护。这是用户标准，不是从创作者经验推导的微信官方阈值，也不等于认可营销准确率、流量预测或每条建议。研究仍须区分产品自述与实测；没有真实报告不能伪称过关。

## 交接

提供可回查来源、正反案例、证据强弱和缺口，让写作 Skill 判断信息增量、文章作用与表达方式。研究材料不必全部进入正文。发布后的优化基于同类内容、同一统计窗口与真实数据；无数据时只提出可验证假设，不制造“预计提升 X%”。
