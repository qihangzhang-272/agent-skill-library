# 发布前只读预览

## 目的

`06-final.preview.html` 是发布前质检产物。它同时展示正式 `06-final.html` 在 677px 公众号正文宽度和 375px 手机宽度下的效果，并检查主题标记、本地断图、标题与图片数量、横向溢出。

它不是排版工作台：没有主题选择、组件卡片、字号滑杆、间距滑杆或样式写回能力。正式样式只来自个人样式目录与 `qihang-layout.ts`。

## 生成

```powershell
bun scripts/build-publish-preview.ts --html <06-final.html>
```

默认在正式 HTML 同目录生成 `06-final.preview.html`。命令返回预览路径、主题检测结果、标题数、图片数和缺失图片路径。

## 发布闸门

- 只做 HTML 排版时，可以生成预览后交付，不进入外部发布。
- 进入公众号草稿箱前，必须生成并查看预览。
- 断图、主题缺失或任一宽度横向溢出时停止发布，修复后重新生成预览。
- 用户明确说“直接进草稿箱”“不用再次确认”时，该授权只免除再次询问；预览与技术检查仍必须执行。
- 草稿箱授权不包含群发授权。
