# 校准案例

这些案例用于校准评分尺度，不是产品理论正文。

## vLLM / Inferact

锚点：8.5-9.0 分，基础设施标准型项目。

核心判断：

- 开源生态极强，贡献者、采用者和硬件/云厂商集成都是强信号。
- 技术层面有 PagedAttention 这类 L1/L2 级别创新。
- 商业化早期收入弱，但被基础设施标准地位覆盖。
- 退出路径强：云厂商、硬件厂商、AI 平台都有战略动机。

评分教训：

- 对基础设施标准型项目，早期无收入不必然压死投资判断。
- A、C、E 三项同时高时，D 的早期弱项可以被里程碑条款管理。

## Hugging Face

锚点：8.0-8.5 分，开源生态商业化平台。

核心判断：

- 社区和平台网络效应是主要护城河。
- 商业化路径已验证：企业订阅、推理 API、平台服务。
- 战略投资者既是验证，也是潜在风险缓释。
- 风险在于云厂商垂直整合，但社区信任和模型生态难以短期复制。

评分教训：

- Open-source hub / registry / platform 可以形成 AI 周期中的高价值商业模式。
- 生态信任和网络效应可以成为比单点算法更强的长期资产。

## 使用方法

给新项目打分时，不要抽象地问“它是多少分”。要问：

- 它的社区更接近 vLLM，还是只有少量 stars 的早期项目？
- 它的商业化更接近 Hugging Face，还是只有 LoI/MOU？
- 它的技术控制点是事实标准，还是普通包装层？
