# 公众号数据图契约

## 边界

本技能既能生成视觉化信息图，也可能被要求画“chart”。遇到精确数量、变化率、排名或时间序列时，先按数据图处理，不把数字直接交给生图模型自由发挥。

## 必需输入

- 读者问题与图要支持的最小判断。
- 原始值及其来源。
- 指标单位、统计口径、时间范围和地域范围。
- 分类或时间字段。
- 来自正文的 Exact text；单项不超过 10 个汉字。

缺任一项时，回到材料 owner 补齐，或改成不声称精确数据的概念插图。

## 形式选择

| 问题 | 首选 |
| --- | --- |
| 谁高谁低 | 横向或纵向条形图 |
| 如何随时间变化 | 折线图 |
| 两个变量是否相关 | 散点图 |
| 总量由什么构成 | 堆叠条形图 |
| 多个对象遵循同一口径 | 小多图 |

不要默认使用饼图、仪表盘、3D 柱状图或装饰性 dashboard。关系、流程和架构交给 `baoyu-diagram`，不要伪装成数据图。

## 生成与验证

1. 在 `structured-content.md` 保存逐字数据和来源。
2. prompt 只决定视觉语言，不能修改数值、单位、顺序或标签。
3. 位图生成后逐项核对数字和文字；任何一项错误都重新生成或改用可复现图表渲染，不在位图上覆盖修字。
4. 图外 caption 写来源、口径和必要的不确定性。
5. 保留可复现数据源；PNG 不是唯一事实载体。
