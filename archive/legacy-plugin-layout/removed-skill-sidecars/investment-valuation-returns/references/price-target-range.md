# Price Target and Decision Range

When an audited model is supplied as an input, use it before interpreting valuation. Otherwise use only supplied facts and explicit assumptions; do not begin with placeholder forecasts or invoke model-building from this method.

## Method reconciliation

- State which methods are applicable: DCF, public comps, precedent transactions, LBO, or another named method.
- Explain why each method is included, excluded, or assigned a weight; do not average methods mechanically.
- Reconcile enterprise value to equity value with dated debt, cash, preferred claims, and diluted shares.
- For public equities, state the valuation date, current price, price target, target horizon, and named LTM or NTM metric. For private deals, provide entry value and a returns range rather than inventing a per-share target.

## Scenario discipline

Show bull, base, and bear cases with the assumptions that change: growth, margin, capital intensity, WACC or exit multiple, leverage, and timing as applicable. Keep outputs traceable to the valuation basis and, when present, the supplied model; identify the one or two assumptions that dominate the range.

## Required method output

```text
Valuation date and currency
Methods considered and weights
Enterprise-value outputs by case
Equity-value bridge
Price target or decision range
Upside / downside and time horizon
Key sensitivities
Method limitations
```
