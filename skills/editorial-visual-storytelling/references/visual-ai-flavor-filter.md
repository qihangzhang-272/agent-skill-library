# Visual AI-Flavor Filter

判断标准仍是频率、分布和功能，不是禁用某种形式。

## 结构层

- 是否把每个抽象名词都装进了方框？
- 是否习惯性生成三步、四象限、五阶段或闭环？
- 是否为了“看起来完整”加入正文并不需要的节点？
- 是否每张图都从左到右完成一次漂亮论证？
- 是否同一张图混用了多个抽象层级？

## 文案层

- 标签是否只是把小标题搬进图片？
- 是否高频使用“从 X 到 Y”“真正的 X”“不是 A，而是 B”？
- 漫画角色是否在说作者的论纲，而不是场景中的话？
- 图片标题是否已经替读者宣布了结论？
- 是否生成了 prompt 未授权的辅助文字？
- 是否每句话离开图片后都像一条可复用金句，却没有一句属于当前场景？
- 连续字幕是否字数接近、句法对称、全部完成一次漂亮升华？
- 是否使用“判断、价值、赋能、重构、沉淀、闭环”等抽象名词代替可见动作？
- 是否出现英文名词化结构的直译，导致中文缺少明确动作主体？
- 画内文字是否超过 10 个中文字符，读起来像正文句子而不是快速指示？
- 是否靠缩小字号、强制换行或拆成多个气泡保留本应移到图外的长句？

## 氛围层

- 人物是否只是一个皱眉的办公人形？
- 材料和工具是否只是摆设，没有改变人物动作？
- 是否靠咖啡、深夜、便签、问号和凌乱桌面批量制造“真人感”？
- 是否把统一蓝橙配色误当成完整风格？
- 画面是否缺少停顿、余白和普通时刻？

## 修复顺序

1. 删除不回答 `Viewer job` 的元素。
2. 删除画面已经表达的文字。
3. 把一个抽象节点替换成可见动作、证据或材料状态。
4. 打破不必要的对称和闭环。
5. 最后才调整颜色、字体和纹理。
