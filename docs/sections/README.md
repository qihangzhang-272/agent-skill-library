# Section Docs

这里放各板块自己的来源、调用链、索引和收录结果。板块入口仍然在 `sections/<section>/README.md`，这里保存更细的文档。

## 放置标准

如果文档只服务一个板块，放在对应 `docs/sections/<section>/` 下。如果它定义整个仓库的规则，放到 `docs/governance/`；如果它是跨板块可复用流程，放到 `docs/workflows/`。
