# Investment-Banking Language Checks

Use this reference after factual and numerical review. Preserve the approved claim; improve only its presentation.

| Avoid | Prefer |
| --- | --- |
| best-in-class | leading, with the specific evidence |
| unique | differentiated, with the stated basis |
| synergistic | specify the revenue, cost, or strategic mechanism |
| robust | quantify the result or state the relevant period |
| transformative | describe the operational or financial change |
| significant | quantify magnitude and comparison base |
| leverage | use, benefit from, or finance, depending on meaning |
| utilize | use |

Check that:

- client, target, buyer, and transaction names use the approved form;
- defined terms are capitalized consistently;
- ticker, exchange, currency, and fiscal-period labels are consistent;
- forward-looking language distinguishes management guidance, consensus, analyst estimate, and scenario;
- confidential information carries the required disclosure label.
