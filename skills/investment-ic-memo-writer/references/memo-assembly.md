# IC Memo Assembly

The writer assembles completed node handoffs; it does not reopen research, create a model, select peers, or resolve an upstream contradiction without flagging it.

## Assembly Rules

- Lead with recommendation, rationale, return logic, and the most decision-relevant risks.
- Keep facts, assumptions, judgments, and unknowns separately labeled.
- Tie financial and return figures to their originating handoff, valuation date, and scenario.
- Preserve material disagreement between upstream nodes; name the decision required instead of harmonizing it silently.
- Use tables for financial history, scenarios, scorecards, risks, and DD priorities where they improve comparability.

## Required Close

End with a clear `Proceed`, `Pass`, or `Conditional proceed` recommendation; conditions must name the evidence or action needed to remove them.
