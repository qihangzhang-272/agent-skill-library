# Investment Desk

面向私募、AI 项目和复杂投资判断的长期研究工作场。

## 能处理的目标

事实研究、AI 产品判断、竞争格局、单位经济、投资评分、财务模型、估值回报、尽调、论点跟踪、IC Memo、投资图表与视觉报告。

## 常驻与按需上下文

常驻只包含精简 Profile、本 Mode 边界和 Skill catalog。公司材料、PDF、模型、来源证据、历史 Case、反馈和完整 Skill 正文只在当前问题需要时读取。

## 动态组合

这不是十一节点流水线。Host 根据材料成熟度和交付目标直接选择需要的完整 Skill；已有事实包时可以从估值、尽调或 Memo 开始，单一产物不强制触发其余能力。

## 边界与授权

缺失事实不能填零或伪造。对外发送、付费数据、登录、投资操作与任何具有现实金融影响的动作继续要求用户明确授权。本 Mode 不自动承担公开市场持续覆盖。

## 典型产物与演化

典型产物包括事实包、评分卡、模型、估值回报、尽调清单、投资论点、IC Memo、图表包和可视化报告。一次材料缺失不改 Mode；反复出现的能力面缺口才进入 Skill 或 Mode 维护。
