# IC Memo Assembly

The writer assembles the accepted revisions of Artifacts 01–09; it does not reopen research, create a model, select peers, or resolve an upstream contradiction by preference.

## Preflight

- Require all nine Artifacts and their completion records.
- Reject any `REWORK` input and any thin Artifact that omits a required analytical obligation.
- Verify that every `READY-WITH-GAPS` item retains attempt references, reason, decision impact, conservative fallback, and revisit trigger.
- Route rejection to the actual responsible node through the current Host owner; do not repair the issue in the Memo.

## Assembly Rules

- Lead with recommendation, rationale, return logic, and the most decision-relevant risks.
- Keep facts, assumptions, judgments, and unknowns separately labeled.
- Tie financial and return figures to their originating Artifact revision, valuation date, and scenario.
- Preserve material disagreement between upstream nodes; name the decision required instead of harmonizing it silently.
- Use tables for financial history, scenarios, scorecards, risks, and DD priorities where they improve comparability.

## Required Close

End with a clear `Proceed`, `Conditional proceed`, `Watch`, or `Pass` recommendation; conditions must name the evidence or action needed to remove them.
