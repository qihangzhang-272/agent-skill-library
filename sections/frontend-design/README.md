# 前端设计

前端设计板块当前只保留索引和调用策略，不在 `skills/` 里保存外部设计技能大包。

## 原则

- 外部设计技能优先通过 `qihang-skill-index` 查询 GitHub 来源。
- 项目需要时，在目标项目里按上游方式安装或引用，不把完整 skill、CLI、脚本和素材搬进本仓库。
- 本仓库只保存选择规则、调用链和质量门。
