# 产品

产品板块收集产品分析、案例研究、场景边界、商业模式和竞争定位相关技能。

当前原则：

- 产品技能服务于投资问题、产品判断和研报链路。
- 技能负责执行分析流程、沉淀判断步骤和触发场景。
- 外部或内部材料只作为输入来源，不把某个知识库设为本仓库的默认上游。
- 如果一个技能明确要作为跨项目迁移包使用，可以随包携带必要 `references/`，但必须在 `catalog/skills.yml` 标注来源和依赖边界。

已收录：

- `ai-product-analyzer`：从 BP / Pitch Deck 商业判断逻辑评估 AI 产品，输出好案例 / 反面教材 / 待观察判断。

待收录方向：

- Good Case / Bad Case 写作与归档
- 客户咨询诊断
- 竞品范式跃迁判断
